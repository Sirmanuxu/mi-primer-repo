# Curso de Git básico

Este repositorio contiene un proyecto sencillo creado para practicar los conceptos
fundamentales de Git.

## Sobre el proyecto

Mi nombre es **Manuel Rocha** y estoy haciendo un curso de Git en la facultad para
aprender a usar el control de versiones y organizar mejor mis proyectos.

El proyecto incluye una página personal básica con información de prueba y estilos CSS
separados en un archivo independiente.

## Archivos principales

- `index.html`: página web con la información personal.
- `styles.css`: estilos visuales de la página.
- `cheat-sheet.md`: resumen de comandos útiles de Git.
- `guia-ssh.md`: guía para configurar el acceso mediante SSH.

## Cómo ver la página

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en un navegador web.

También puedes abrir la carpeta del proyecto con Visual Studio Code y utilizar su vista
previa para revisar los cambios.

## Objetivo del curso

Practicar operaciones como:

- Crear y modificar archivos.
- Consultar los cambios realizados.
- Crear commits.
- Trabajar con ramas.
- Sincronizar cambios con un repositorio remoto.
